# Landschaftsgärtner & Hausmeisterservice Alimi

Statische Website (HTML/CSS/JS, kein Build) für Nermin Alimi, Würselen.

- `index.html`: Startseite (Hero-Slider, Über mich mit Scroll-Effekt, Leistungen, Galerie, Ablauf, Einsatzgebiet, Kontakt)
- `impressum.html`, `datenschutz.html`: Rechtstexte (gelb markierte Stellen noch ausfüllen)
- Schriften (Lexend, Source Sans 3, SIL OFL) liegen lokal in `fonts/`, also keine Verbindung zu Google

Lokal ansehen:

```bash
python -m http.server 8134
```
